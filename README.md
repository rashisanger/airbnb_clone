# Airbnb Clone

## Overview

A full-stack Airbnb-inspired web application built as an SDE Fullstack assignment.

The application will allow users to browse properties, search and filter listings, view property details, book stays, manage trips, and allow hosts to create and manage their listings.

## Tech Stack

### Frontend
- Next.js 14
- TypeScript
- React
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- SQLite
